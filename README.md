# JAE JD Creator

**AI-powered Job Description creator and JAE Committee evaluation platform for Aditya Birla Capital.**

Built with React, Node.js, PostgreSQL, and local Ollama LLM (Qwen 2.5). Designed to move to Azure OpenAI + Azure PostgreSQL for production.

---

## Features

- **JD Wizard** — 8-step guided JD creation with LOB-aware templates

- **AI-Generated Content** — Hay-compliant Job Purpose, Context, Challenges, Accountabilities

- **JAE Committee Simulation** — 4-agent AI debate (Business, HR, Finance, JAE COE)

- **Hay Guide Chart Scoring** — Know-How + Problem Solving + Accountability

- **Auto Band Recommendation** — JB 1 (Group CEO) to JB 10 (Junior IC)

- **Word + PDF Export** — ABSLAMC template format

- **Multi-LOB Support** — AMC + NBFC business rules

---

## Tech Stack

- **Frontend:** React 18 + Vite + Tailwind CSS + Zustand

- **Backend:** Node.js 20 + Express

- **Database:** PostgreSQL 16

- **LLM:** Local Ollama (Qwen 2.5:1.5B) → Azure OpenAI (future)

- **PDF:** pdfkit

- **Word:** docx
